# Log Exporter App

[English version](README.md)

Eine DNS-App für ZenitiumDNS, die Protokolleinträge über einstellbare Exportwege ausgibt.

## Konfiguration

Die App wird über `dnsApp.config` (JSON) eingestellt.

> Diese README ist bewusst knapp gehalten. Die unterstützten Konfigurationsschlüssel stehen in der mitgelieferten `dnsApp.config` in diesem Ordner.
